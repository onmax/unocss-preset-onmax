# UnoCSS Preset Uno Vue

A UnoCSS preset to work seamlessly with the Uno Vue ecosystem.

## Installation

```bash
npm install unocss-preset-unovue
```

## Usage

This preset is a wrapper of different presets which can be used as a standalone, but if you need all of them this preset is just syntactic sugar.

- [UnoCSS Preset Reka UI](../unocss-preset-reka-ui/)
- [UnoCSS Preset ShadCN](../unocss-preset-shadcn/)
